# BluffCards — концепт

Цифровая версия «Верю — не верю» по домашним правилам: проверяется **ровно одна карта** из выложенной пачки, пачка без лимита, четвёрки в руке уходят в минусы.

## Первый релиз
Главная открывается сразу с гостевым или восстановленным платформенным профилем. Три входа — бесплатный «На вылет», бесплатная «Быстрая игра», платный «Клуб профессионалов». Друзья, таблица лидеров и способы входа доступны через значки. Сервер матчмейкинга запускает заполненный стол и через 20 секунд добирает пустые места ботами. В HTML-прототипе сеть моделируется локально. Оболочка платформы может передать подтверждённую сессию через `BluffCardsPlatform.restoreSession({guestId, interactive:false})`, вернув `{playerId, provider}`.

## Столы (кратко)
- **Стол «На вылет»** (основной) — серия партий, после каждой выбывают игроки с максимумом минусов, пока не останется один.
- **Стол «Быстрая игра»** — одна партия, мало фишек.

## Рынок (кратко)
- Аналоги: Cheat / Bluff / I Doubt It / Bullshit / Doubt (JP) — везде вскрывается вся пачка и лимит 1–4 (до 8) карт.
- Нашей механики (одна карта, перевод без лимита, минусы за четвёрки, игра на вылет) в сторах нет — это УТП.
- Рабочее SEO-название: «Верю — не верю: Одна карта» / EN «Bluff: One Card Check».
