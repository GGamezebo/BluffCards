# BluffCards — «Верю — не верю: Одна карта»

Онлайн-игра в блеф по домашним правилам: пачка любого размера, проверяется **ровно одна карта**
последней пачки, четвёрки в руке уходят в открытые минусы. Столы «На вылет», «Быстрая игра»,
клуб профессионалов со взносом, комнаты друзей, учебная раздача, лидерборд.

- Клиент — Godot 4.7 (GDScript, рендерер Compatibility), портрет на телефоне, ландшафт на ПК/вебе.
- Сервер — Nakama + Postgres, вся логика партии в авторитарном матче на TypeScript (`server/`).
- Дизайн и правила — `concept/` (HTML-атлас экранов: `concept/design/index.html`).

## Запуск локально
1. Сервер: см. [server/README.md](server/README.md) (`npm run build`, `docker compose up -d`).
2. Если сервер не на `127.0.0.1:7350` — скопируй `online_local.tres.example` в `online_local.tres` и впиши адрес.
3. Открой проект в Godot 4.7 и запусти (F5). Каждую сцену можно запустить отдельно (F6) — она покажет демо-стол.

## Тесты
```
godot --headless --path . --script res://tests/run_all.gd      # клиент
cd server/ts && npm test                                        # правила и боты
godot --path . --script res://tests/e2e/play_smoke.gd -- --shots=<папка>   # живая партия с локальным сервером
```

## Веб-сборка
Пресет `Web` (однопоточный, без требований COOP/COEP) → `build/web/index.html`.
Странице по HTTPS нужен сервер с WSS (`use_ssl`).
