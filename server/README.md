# BluffCards — сервер Nakama

Сервер авторитарный: колоду, руки, стопку, проверку, добор, ботов, таймер, фишки и лидерборд считает он.
Клиент присылает только намерения («сходить», «перевести», «не верю», реакции) и получает свой вид стола —
свою руку целиком, у соперников только число карт и минусы.

## Что нужно
- [Docker Desktop](https://www.docker.com/products/docker-desktop/) (Windows: бэкенд WSL2).
- Node.js 18+ — чтобы собрать модуль из TypeScript.

## Сборка и запуск

```powershell
cd server/ts
npm install
npm run build     # пишет server/nakama/modules/index.js
npm test          # сценарии правил + 3000 партий бот-против-бота
cd ..
copy .env.example .env      # затем поменяй пароли и ключи в .env
docker compose up -d
docker compose logs -f nakama   # ждём "bluffcards module loaded"
```

Проверка: http://127.0.0.1:7350/healthcheck → `{}`. Консоль администратора — только с этого компьютера:
http://127.0.0.1:7351/ (логин и пароль из `.env`). После правки TypeScript: `npm run build` и `docker compose restart nakama`.

**Порт занят другим сервером** (например, Nakama от GoofyBalls на 7350): в `.env` поставь `NAKAMA_PORT=7360`,
`NAKAMA_CONSOLE_PORT=7361`, а в игре — `online_local.tres` (скопируй `online_local.tres.example` в корне проекта,
впиши `port = 7360`). Файл не попадает в git, но попадает в сборки и запуск из редактора.

## Настройки баланса
Все числа — в `ts/src/config.ts` (таймеры, задержки ботов, места, стартовые фишки, антиспам реакций).
Для тестов часть можно переопределить в `nakama/local.yml` → `runtime.env`:
`BC_SEARCH_SEC` (ожидание соперников, 20 с), `BC_BOT_DELAY_SCALE` (1 = «человеческие» 1–6 с), `BC_REVEAL_SEC`.

## Что внутри
| Файл | Что |
|---|---|
| `ts/src/rules.ts` | Правила одной партии и серии «на вылет», призы. Чистая логика без Nakama |
| `ts/src/bot.ts` | Боты: видят только то, что видел бы человек на их месте |
| `ts/src/match.ts` | Авторитарный матч: места, ожидание, ходы, таймеры, «отошёл», межпартийная пауза, итог, взносы и призы |
| `ts/src/rpc.ts` | RPC лобби: профиль, поиск стола, комнаты и компании, лидерборд, друзья, жалобы, удаление аккаунта |
| `ts/src/store.ts` | Хранилище: кошелёк, лидерборд, профиль, недавние соперники, компании, коды комнат, блок-лист |
| `ts/test/rules.test.ts` | Тесты правил |
| `docker-compose.yml`, `nakama/local.yml` | Postgres + Nakama 3.37 |

## Ограничения первого релиза
- Вход — гостевой по устройству. Google / Apple / Telegram требуют SDK магазинов и пока отвечают «появится в версии для магазина».
- Приглашения доходят в игру уведомлением, пока игрок онлайн; пуши (FCM / APNs) — с платформенными сборками.
- Веб-версии нужен сервер с HTTPS/WSS (`use_ssl` в `online_local.tres` / `BLUFF_NAKAMA_SSL=1`): страница по HTTPS не может ходить на `ws://`.

## Безопасность
Наружу открыт только игровой порт. Перед выходом в интернет поменяй в `.env` все ключи и пароли,
а `server_key` в игре — на тот же `NAKAMA_SERVER_KEY`.
